# VLC-Based Passive-Powered Sensing and Control Module for Indoor Farming

## About the Project

This is my final-year research project at the University of Colombo, Faculty of Technology.

The project explores a Visible Light Communication (VLC)-based system for sensing and controlling environmental conditions in indoor farming.

The system aims to harvest energy from grow lights to power a sensing and control module while using optical communication instead of conventional wireless communication technologies.

## My Contribution

**Role:** Communication and VLC System

My main project area focused on the communication system and its integration with the sensing and control module.

## Technologies and Components

- MSP430G2553 microcontroller
- Infrared (IR) communication
- Environmental sensors
- Light intensity sensing
- Soil moisture sensing
- Energy harvesting
- Low-power embedded systems

## Project Objective

To explore a low-power sensing and control solution for indoor farming that reduces dependence on wired power and radio-frequency communication.
